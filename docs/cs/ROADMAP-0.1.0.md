# Plán LAN Drop

## 0.1.0 — funkční prototyp
- [x] C# server a české responzivní rozhraní pro Windows a Safari.
- [x] Místní QR, schválení telefonu, odpojení a expirace relace.
- [x] Přenos souborů oběma směry, více souborů, průběh a storno.
- [x] Cílová složka, ochrana před přepsáním, zápis na disk po částech.
- [ ] Ruční test: 20 fotek z iPhonu do Windows a video opačně.
- [ ] Ruční test Safari: zamknutí, změna sítě, přepnutí aplikace.

## 0.2.0 — pohodlí na Windows
- [ ] Nativní okno a dialog pro výběr složky.
- [ ] Uložení nastavení, výběr správného síťového adaptéru.
- [ ] Ikona v oznamovací oblasti, otevření cílové složky.
- [ ] Omezení souběžných přenosů a volitelné potvrzení jednotlivých příjmů.
- [ ] Úklid zbytků po pádu, prázdné soubory a přehled volného místa.

## 0.3.0 — odolnější přenos
- [ ] Obnova přerušeného nahrávání a kontrolní součty.
- [ ] Zabezpečené spojení s promyšleným párováním na iOS.
- [ ] Výběr příjemce a oddělení sdílených souborů mezi zařízeními.

## 1.0.0 — distribuce
- [ ] Instalátor, podpis aplikace, ikona a verze.
- [ ] Testy na fyzickém iPhonu a různých sítích, včetně velkých videí.
- [ ] Srozumitelné řešení firewallu, kolize portu a nedostatku místa.
