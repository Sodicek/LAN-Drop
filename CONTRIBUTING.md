# Contributing

Use English for code, issues, pull requests and primary documentation. English and Czech are maintained UI languages; new language contributions are welcome.

Build on Windows with .NET 10 SDK. Run the commands in README before submitting a change. Include the concrete behavior changed and the validation performed. Do not commit binaries, private files, console output containing session tokens or machine-specific settings.

Start with the product design and roadmap. Changes to transport trust, permissions, filesystem access, dependencies or update distribution need a clear threat-model explanation. Physical iPhone testing cannot be replaced by loopback CI.
